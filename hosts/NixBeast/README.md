# NixBeast

My primary device. This is my hand-built PC. It's a bit of a beast, hence the
name. (Historically has been WinBeast and HyprBeast).

It's entirely AMD and Corsair, so much so I spent extra making sure all my fans
matched so there would't be colour differences in the RGB.
